# Simple MERN Todo List

A minimal todo list app using MongoDB, Express, React (Vite), and Node.js.

## Features
- ✅ Add todos
- ✅ Mark as complete
- ✅ Delete todos
- ✅ View statistics

## Dependencies
**Backend:** Only 3 packages (express, mongoose, cors)  
**Frontend:** Only 5 packages (react, react-dom, vite, @vitejs/plugin-react)

Much lighter than Create React App! ⚡

## Setup

### 1. Install Backend
```bash
cd backend
npm install
```

### 2. Install Frontend
```bash
cd ../frontend
npm install
```

This will be **much faster** - only ~50 packages instead of 1400+!

### 3. Start MongoDB
Make sure MongoDB is running:
```bash
mongod
```

### 4. Start Backend
```bash
cd backend
npm start
```
Backend runs on http://localhost:5000

### 5. Start Frontend
Open a new terminal:
```bash
cd frontend
npm run dev
```
Frontend runs on http://localhost:3000

## That's it! 🎉

Open http://localhost:3000 in your browser.
